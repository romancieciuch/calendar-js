Aplikacja Kalendarz

Uruchomienie aplikacji:
- rozpakuj archiwum zip
- uruchom w przeglądarce plik index.html, znajdujący się w głównym katalogu strony

Wymagania systemowe:
- przeglądarka stron www
- włączony Java Script
- przeglądarka obsługuje Local Storage
- aplikacja może działać też jako PWA

Katalogi:
- css - style css
- images - obrazki
- js - główne skrypty aplikacji
- storage - miejsce na pliki json, do wymiany pomiędzy urządzeniami
- sync - skrypt php służący do zapisu danych z kalendarza do fizycznych plików na serwerze
- views - widoki aplikacji
